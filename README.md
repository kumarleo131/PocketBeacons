# Pocket Beacons

Pocket Beacons is a 1.21.11 Fabric mod that adds a portable beacon item for selecting and applying effects for on the go beacon usage.

## Features

- Portable beacon interface opened from an item
- Fuel-based activation system  

## Dependencies

This mod is built using the following:

- Minecraft
- Fabric Loader  
- Fabric API  
- UI Lib
